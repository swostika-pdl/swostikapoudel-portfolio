DOMAIN SCANNER

I developed a Domain Scanner project that analyzes a target domain by identifying open ports, detecting running services, and assessing potential security risks. The tool performs automated scanning to discover exposed services, evaluates their associated vulnerabilities, and categorizes the overall risk level. It helps security professionals and students gain insights into a system's security posture and supports proactive vulnerability management and risk assessment.

CTF Writeup Collection

50+ documented CTF solutions from TryHackMe, HackTheBox, and PicoCTF. Covers SQLi, XSS, IDOR, SSRF, reverse engineering, forensics, and crypto. Each writeup includes attack methodology, tool usage, and defensive recommendations.

Home SIEM Detection Lab

Splunk-based home SIEM that ingests Windows Event Logs and Sysmon. Custom correlation rules mapped to MITRE ATT&CK detect lateral movement, credential dumping, and PowerShell abuse. Includes interactive dashboards.

Splunk Sysmon MITRE ATT&CK Detection Eng.
Phishing Simulation Lab

Controlled phishing awareness lab using GoPhish. Simulates credential harvesting, spear-phishing campaigns, and email header analysis. Used to study human-layer vulnerabilities and train detection of phishing TTPs.

GoPhish Social Engineering Awareness Training
Malware Analysis Sandbox

Isolated VM-based malware analysis environment. Studies malware behavior: process injection, persistence mechanisms, C2 communication patterns. Write-ups on analyzed samples with IOC extraction and YARA rule development.
